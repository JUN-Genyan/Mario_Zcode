- 已装 **Fennara** 插件；ZCode 配置了 MCP 服务器 `C:\Users\27200\AppData\Local\Fennara\bin\fennara-mcp.exe`
- 本会话未直接加载 fennara MCP 工具 → 我将写一个标准 MCP stdio 客户端（Node v24）与 fennara-mcp.exe 进行 JSON-RPC 握手并调用其工具（initialize → tools/list → tools/call）
- Fennara 工具集：`fennara_status`、`get_scene_tree`、`get_node_properties`、`write_or_update_file`（自动 GDScript 诊断）、`run_scene_edit_script`（编辑器内建场景，自动场景校验）、`run_asset_import_script`、`project_settings`、`runtime_session/runtime_script`（运行游戏观察）、`screenshot_scene` 等
- 文档红线：**不手写 .tscn/.tres 文本，一切场景由编辑器序列化**（这正是"充分利用编辑器节点功能"）

## 游戏设计（单关完整可玩）
横版 1 关（~140×18 tile，16px tile，像素风），经典 SMB 玩法：
- 玩家：跑/跳（土狼时间、跳跃缓冲、可变跳高）、踩怪、顶"?"砖出金币、碰怪/坠落死亡、3 条命、重生
- 敌人 Goomba×N：巡逻折返、被踩压扁（粒子烟尘）
- 金币（旋转动画）、?砖→用过的砖、水管、砖块平台、深坑、终点旗（彩带粒子）
- HUD：金币数、生命♥、倒计时；胜利/失败画面；R 重开
- 视听：视差云山背景、芯片音效（跳/金币/踩/顶砖/死亡/胜利）+ 循环 BGM（全部程序生成，无外部素材）

## 实施步骤

**0. MCP 通道**
- 写 `tools/mcp_client.mjs`：spawn fennara-mcp.exe，MCP 握手后按 CLI 参数调用工具（`--list` 列工具 / `<tool> <json>` 调用），输出结果
- `fennara_status` 确认编辑器连接与活动项目；若项目未在 Fennara dock 选中 → 用 computer-use 在编辑器 UI 中选中

**1. 项目设置**（`project_settings`）：主场景、窗口 1280×720 + canvas_items/keep、InputMap（A/D/←/→ 移动、Space/W/↑ 跳、R 重开）、物理层命名、Nearest 纹理过滤、天空蓝背景色

**2. 资产生成**：`tools/gen_assets.gd` 用 `write_or_update_file` 写入，经 MCP 的编辑器脚本工具在编辑器内运行生成 `assets/`：像素画 PNG（tiles 9 格 / player 4 帧 / goomba 2 帧 / coin / flag / cloud / hill / heart）+ 6 个音效 WAV + BGM WAV，并触发导入

**3. 游戏脚本**（`write_or_update_file`，逐个拿诊断结果）：`player.gd`、`enemy.gd`、`coin.gd`、`flag.gd`、`hud.gd`、`game.gd`

**4. 场景构建**（`run_scene_edit_script`，编辑器内创建节点并保存 .tscn，自动场景校验）：
- `player.tscn`（CharacterBody2D+AnimatedSprite2D+CollisionShape2D+Camera2D+AudioStreamPlayer）
- `enemy.tscn`（含 CPUParticles2D）、`coin.tscn`（AnimationPlayer 旋转浮动）、`flag.tscn`（彩带粒子）、`hud.tscn`（CanvasLayer+Container 布局）
- `main.tscn`：TileMapLayer+内嵌 TileSet（每格碰撞多边形）+ParallaxBackground+KillZone+Timer（编辑器信号连接）+音频播放器+实例化 Player/HUD；**关卡 ASCII 布局脚本在编辑器内 set_cell 铺好并保存进 .tscn**（tile 数据成为编辑器资产，非运行时生成）

**5. 运行验证与迭代**
- 诊断/场景校验清零，`get_scene_tree` 抽查
- 经 MCP 运行游戏 + 截屏：验证跑跳、吃金币、踩怪、顶砖、死亡重生、通关画面；发现视觉/手感问题即修复

## 回退
若 MCP 连接失败（daemon 未运行/项目未选中且 dock 无法自动化）→ 退回直接写 .tscn/.gd 文件（编辑器可加载），并在总结中如实说明。
